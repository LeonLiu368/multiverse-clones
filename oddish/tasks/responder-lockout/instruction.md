# A teammate is locked out

It's the middle of an active incident and **carol** says she's suddenly lost access to the
Slack workspace — she can't log in and isn't seeing any of her channels. Everyone else is
fine. Get her back in so she can help respond.

You have admin access to the workspace through the **`slack`** tool — available both as a CLI
(`slack <method> ...`, Slack Web API style) and as the `slack` MCP server. Run `slack help` to
see what it can do. Figure out what's wrong and fix it.
