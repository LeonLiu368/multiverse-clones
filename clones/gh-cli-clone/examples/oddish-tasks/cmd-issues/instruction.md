# Manage a project with `gh`

`gh` is installed and authenticated (`gh auth status` confirms). The repo
**`acme/tracker`** exists. Using `gh`, do **all** of the following:

1. Create two labels in `acme/tracker`: `bug` and `duplicate`.
2. Create a milestone titled `v1.0`.
3. Open an issue titled exactly `Login fails` (any body).
4. Add a comment `looking into this` to that issue.
5. Add an `eyes` reaction to that issue.
6. Edit the issue's title to `Login fails on Safari`.
7. Close the issue, then reopen it.
8. Delete the `duplicate` label.
9. Create a throwaway repo named `scratch`, then delete it.
10. Rename the `tracker` repo to `tracker-v2`.
