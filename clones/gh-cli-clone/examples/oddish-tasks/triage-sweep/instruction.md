# Triage the backlog in `acme/inbox`

The `acme/inbox` repo has a backlog of untriaged issues. Work through them:

- Any issue that reports a **crash or a security problem** is a real bug: label it
  `bug` and add it to a new `v1.1` milestone.
- If two issues are clearly **the same report**, close the duplicate with a brief
  comment saying it's a duplicate.
- Leave anything that's neither a crash/security issue nor a duplicate alone.

You have `gh`. Read the issues and triage them.
