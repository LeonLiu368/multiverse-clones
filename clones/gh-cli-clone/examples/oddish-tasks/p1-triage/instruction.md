# Triage an issue with `gh`

The `gh` CLI is installed and already authenticated against a Git forge
(`gh auth status` confirms it). The repo **`acme/triage`** has an open
issue **#1**.

Using `gh`, do all three:
1. Create a label named exactly `wontfix` in `acme/triage`.
2. Comment `closing as wontfix` on issue #1.
3. Close issue #1.
