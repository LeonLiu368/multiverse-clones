# Data removed

This held `records.json.gz`, the Logfire "prod corpus": real production telemetry from Abundant's internal services. It was removed from the public copy of this repository, including its history.

The `logfire-service:prod-v1` image and the `logfire-incident-rca` task need a corpus here. Any list of Logfire records in the same shape works, gzipped as `records.json.gz`; `seed-dashboard/samples/logfire.records.json` shows the format.
